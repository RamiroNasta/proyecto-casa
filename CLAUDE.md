# Instrucciones para Claude Code — proyecto-casa (repo PÚBLICO)

Este repo es público: cualquiera puede leerlo. Solo contiene el plano de implantación para compartir con la arquitecta.

- Archivos permitidos: `index.html`, `una-planta/index.html` (anteproyecto de una planta, aprobado por Ram el 29/09/2026; es copia de `proyecto-casa-docs/planos/anteproyecto-una-planta.html`), `modular/index.html` y `modular/pedido-cotizacion-modular.pdf` (pedido de cotización para proveedores modulares, 01/10/2026; copias de `proyecto-casa-docs/planos/pedido-cotizacion-modular.*`, sin montos ni nombres de proveedores), `README.md`, `.nojekyll`, este `CLAUDE.md`.
- No agregues documentación del proyecto, notas internas, presupuestos, mails ni datos personales. Esa información vive en el repo privado `proyecto-casa-docs`.
- `index.html` tiene que ser autocontenido (con `<!doctype html>`, `<head>` y `<body>` propios) y quedar en la raíz de `main`: GitHub Pages lo publica en https://ramironasta.github.io/proyecto-casa/
- Nunca `git add -A` ni `git add .`: agregá los archivos por nombre.
